# PicFlip

PicFlip is a local-first desktop media conversion toolkit for Windows and macOS.

It converts images, PDFs, audio, and video directly on your computer without uploading your media to a PicFlip server.

## Privacy

- Media processing happens locally on your computer.
- No PicFlip account is required.
- No analytics or cloud media conversion.
- No automatic media uploads.
- Network access is used only for user-initiated update checks/downloads and external links.

## Downloads

Download PicFlip from the **Releases** section of this repository.

> PicFlip 1.0.0 is currently distributed without Windows Authenticode signing or Apple Developer ID notarization. Windows SmartScreen or macOS Gatekeeper may therefore display a warning. These warnings are related to developer identity/reputation and do not by themselves mean that the application has been identified as malicious.

## Updates

From PicFlip 1.0.0 onward, **Settings → Check for updates** checks the official release channel in this repository.

The updater uses cryptographic signatures to verify supported update packages. Updater signing is separate from Windows Authenticode or Apple Developer ID code signing.

## Source code
